Show HN: Notate – on-device Whisper transcription for iPhone and Mac

Notate runs WhisperKit locally, so audio is decoded on the phone or Mac and never leaves it. It transcribes live from the microphone in two second windows, re-decoding only the trailing eight seconds each tick so latency stays flat as a recording grows. Models are picked by device memory and copied out of the purgeable HuggingFace cache into Application Support so they survive storage pressure. Everything is included for one $0.99 payment: live dictation and file transcription, unlimited, across every language Whisper knows. Source is on GitHub and there is a web build at notate.jaybulb.com.
